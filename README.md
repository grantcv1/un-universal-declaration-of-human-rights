# The Universal Declaration of Human Rights in Akoma Ntoso

The Universal Declaration of Human Rights of December 10, 1948, in Akoma Ntoso XML, in Arabic, Chinese, English, French, Russian and Spanish, with a CSS stylesheet. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `universal-declaration-of-human-rights.xml` | The Akoma Ntoso document, with all six languages |
| `universal-declaration-of-human-rights.css` | The stylesheet, linked from the XML |
| `view.html` | A page that shows one language at a time |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser. That shows the six languages one after another. `view.html` needs a web server, because it loads the XML with a script.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** A `<documentCollection>` holds six `<component>` elements, each with a complete `<statement name="declaration">`, its own language expression and its own metadata. The order is English, then the other languages as the UN site lists them.
- **Parts of each text:** The recitals are `<recital>` elements, the proclamation is in `<formula name="enactingFormula">`, and the 30 articles are `<article>` elements. Numbered clauses are `<paragraph>` elements.
- **Identifiers:** Eids carry the language, so `cmp_fra__art_19` is Article 19 in French.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither.
- **Number:** The FRBR number is the General Assembly resolution, 217 A (III).
- **Differences among the texts:** Each text keeps the paragraphing of its source. The French text numbers two clauses in Article 2, which the others do not. In the English source the clause numbers are list numbers, and they are given in `<num>` here.

## Sources

Text: the [United Nations website](https://www.un.org/en/about-us/universal-declaration-of-human-rights) and its versions in the other five languages. The words match those pages, and the check compares each language with its source.
